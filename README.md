# El Bash order screen

The iPad screens loaded by the El Bash Orders Apps Script. Not part of the menu website.

- `page.html`: the order screen and sales report (`…/exec`)
- `kitchen.html`: the kitchen screen (`…/exec?screen=kitchen`)
- `Code.gs`: the Apps Script that serves them and reads and writes the El Bash – Orders & Sales sheet. Changes to it must be pasted into the Apps Script project and redeployed; the HTML files update by themselves.
